# Recursos provisionales

Archivos temporales, **no son arte del juego**. Se sustituyen cuando exista el arte definitivo.

| Archivo | Uso |
|---|---|
| `icon-192.png`, `icon-512.png` | Iconos del manifiesto (`manifest.webmanifest`). Color plano con un círculo liso: solo hacen válido el manifiesto para poder instalar el juego como app en Android. |

Para cambiarlos, reemplaza los PNG manteniendo el nombre y el tamaño (o actualiza las rutas en `manifest.webmanifest`).
